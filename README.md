# Music Video Maker

Делает видео «трек + персонаж на фоне»: визуализатор от звука, название, автор, полоска прогресса и таймер.

## Веб-версия (работает и в браузере телефона)
https://faraontt.github.io/music-video-maker/

Чтобы ссылка заработала, один раз включи Pages: **Settings → Pages → Source: GitHub Actions**, затем открой вкладку Actions → *Deploy web version* → Run workflow.

## Android APK
GitHub сам собирает APK после каждого изменения в `web/`. Скачать: **Releases → Android APK (latest) → MusicVideoMaker.apk**.
При первой установке разреши установку из неизвестных источников. Если новая сборка не ставится поверх старой из-за подписи, сначала удали старую.

Если сборки нет, открой вкладку Actions → *Build Android APK*: там видно, на каком шаге она остановилась.

## Как пользоваться
1. Выбери фон-видео и музыку, впиши название и автора.
2. Нажми «Создать видео». Запись идёт в реальном времени, не сворачивай приложение и не блокируй экран.
3. Скачай результат (в APK: «Сохранить / поделиться»).

Результат сохраняется в `.mp4`, а если телефон не умеет, то в `.webm`.
